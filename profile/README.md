# DotNetBoost

**Open-source libraries that help .NET developers build web apps faster.**

DotNetBoost is a growing collection of lightweight, focused libraries for the .NET ecosystem. Each one targets a common piece of boilerplate that slows teams down — so you can spend less time re-solving the same problems and more time shipping features.

---

## 📦 Libraries

| Library | Description | Status |
|---|---|---|
| **Database Settings Manager** | Manage application settings directly from your database, with a clean API for reading, updating, and caching config values at runtime. | ✅ Available |
| **Multilingual** | Simplify localization and multi-language support in .NET web apps. | 🚧 Coming soon |

More libraries are planned — this list will keep growing.

---

## 🚀 Why DotNetBoost?

- **Focused** — each library solves one problem well, instead of trying to be a framework.
- **Practical** — built from real-world needs in .NET web development.
- **Lightweight** — minimal dependencies, easy to drop into existing projects.
- **Actively growing** — new tools are added as common pain points come up.
